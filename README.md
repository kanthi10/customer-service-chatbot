Customer Service Chatbot

Project Overview

A simple rule-based customer service chatbot built using Python.

Features

- Responds to greetings: hello, hi, and hey.
- Provides refund instructions.
- Answers order-related questions.
- Provides sample support hours and contact details.
- Responds to thank-you messages.
- Exits when the user types "bye".
- Handles unknown questions.

Technologies Used

- Python
- Google Colab

How It Works

The chatbot accepts a user's message, checks predefined conditions, and displays the matching response. It continues until the user types "bye".

Testing

Tested using greetings, refund requests, order inquiries, support hours, contact inquiries, and goodbye commands.

Limitations

This is a rule-based chatbot. It does not use a trained AI model or connect to a real customer database.

The chatbot was tested with different customer queries.

- Greeting test: Enter "hello" and check whether the chatbot greets the user.
- Refund test: Enter "refund" and check whether refund guidance appears.
- Order test: Enter "orders" and check whether order-related guidance appears.
- Support hours test: Enter "hours" and check whether support timings appear.
- Exit test: Enter "bye" and check whether the chatbot exits.

All these tests are intended to verify that the chatbot responds to supported inputs correctly.

conclusion

This project demonstrates Python input handling, conditional statements, loops, and basic testing.
